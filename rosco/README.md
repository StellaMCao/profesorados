# 🎯 El Rosco - Pasapalabra para Profesorados

Juego interactivo estilo **Pasapalabra (El Rosco)** para uso en clases, talleres y profesorados. Desarrollado en HTML5, CSS3 y JavaScript moderno, 100% autocontenido y listo para ejecutarse sin necesidad de conexión a internet ni servidor.

---

## 🚀 Cómo Usarlo

1. Abre [`rosco/index.html`](file:///C:/Users/stell/.gemini/antigravity/scratch/rosco-pasapalabra/rosco/index.html) directamente con cualquier navegador web (Chrome, Edge, Firefox, Safari).
2. Tienes disponible el botón **"❓ Ayuda"** para consultar las reglas y atajos en cualquier momento.

## 🕹️ Modos de Juego

Puedes alternar entre los dos modos desde el encabezado con un solo clic:

### 1. ⌨️ Modo Automático (Escribiendo / Estudiante)
- Pensado para cuando el alumno juega de forma autónoma en la computadora.
- Escribe la respuesta en el campo de texto.
- <kbd>Enter</kbd>: Validar respuesta.
- <kbd>Espacio</kbd> (con campo vacío) o <kbd>Shift + Enter</kbd>: **Pasapalabra**.

### 2. 🎓 Modo Docente (Oral / Manual)
- Pensado para **clases grupales, proyecciones y dinámicas en el aula**.
- El alumno responde **hablando en voz alta**.
- El docente o moderador marca manualmente el resultado con un clic o atajo de teclado:
  - **`[ ✓ Correcto (1) ]`** o presionar tecla <kbd>1</kbd> o <kbd>C</kbd>.
  - **`[ ✗ Incorrecto (2) ]`** o presionar tecla <kbd>2</kbd> o <kbd>I</kbd>.
  - **`[ ↻ Pasapalabra (3) ]`** o presionar tecla <kbd>3</kbd>, <kbd>P</kbd> o <kbd>Espacio</kbd>.
- Botón **`👁️ Solución`** (o tecla <kbd>S</kbd>): Muestra u oculta la respuesta correcta en pantalla para que el docente pueda consultarla discretamente.
- Botón **`Escuchar`**: Lee la definición en voz alta mediante síntesis de voz (TTS).

## 🎉 Efectos Festivos y Resumen de Partida

- **En cada acierto:** Ráfaga de confeti de colores, halo verde y frases festivas de felicitación flotantes.
- **Al completar el rosco:**
  - Si es **Rosco Perfecto (26 de 26)**: Lluvia completa de confeti, fanfarria musical de triunfo y felicitación de bote ganado.
  - Si hay fallos: Ventana con desglose interactivo y botón de filtro **`[ ✗ Solo Fallos ]`** para repasar en clase las definiciones no acertadas.

## 📝 Formato de Lista de Palabras

En el menú **"Personalizar"**, puedes pegar cualquier lista con el formato:

```text
Palabra: Definición
```

Ejemplo:
```text
Ansiedad: Estado de inquietud o agitación del ánimo...
Bipolar: Trastorno caracterizado por fluctuaciones...
Conductismo: Corriente psicológica basada en la conducta observable...
```

## 💾 Exportar como HTML Independiente

- Haz clic en **"Personalizar"**.
- Elige el tiempo en segundos y pega tu lista de palabras.
- Pulsa **"Exportar como HTML"** para descargar un archivo único con todo listo para compartir con tus alumnos o colegas.
